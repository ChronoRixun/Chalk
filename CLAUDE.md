# CLAUDE.md — Chalk

Guidance for Claude Code working in this repo.

## What this is

**Chalk** is a game-night scorekeeper for iPhone and Android, built to ship on both the App Store
and Google Play as a cheap paid app. Owen directs and tests on devices; Claude writes all the code.
Everything is local-only: no backend, no accounts, no analytics, no ads.

## Stack

- Expo SDK 57, Expo Router (file routes in `src/app/`), React Native 0.86, React 19, TypeScript.
- UI: React Native Paper (MD3). Icons come from `@expo/vector-icons` via the `settings.icon`
  prop on `PaperProvider` in `src/app/_layout.tsx`. Do not add `react-native-vector-icons`.
- State: zustand with `persist` to AsyncStorage (`src/store/games.ts`). Whole-game objects are
  replaced immutably; no immer.
- React Compiler is on (`experiments.reactCompiler`). Write plain hooks; never mutate state.
- Expo changes between SDKs. Check https://docs.expo.dev/versions/v57.0.0/ before using an
  Expo API that is not already used in this repo.

## Layout

```
src/app/            routes: index (home), new-game (modal), game/[id]/index, game/[id]/history
src/components/     PlayerCard, AmountDialog, ActionSheetDialog, ConfirmDialog, EmptyState
src/store/games.ts  the one store
src/lib/scoring.ts  pure functions: totals, standings, outcome, round table, share text
src/lib/haptics.ts  tap/thud/success/warn, no-ops on web
src/constants/      presets.ts (game rules), theme.ts (chalkboard palette + MD3 themes)
```

## Running

- `npx expo start` then Expo Go on a phone. iOS and Android both work with no native build.
- Web preview for quick UI checks: `.claude/launch.json` → `chalk-web` (port 8081).
- `npm run typecheck` before claiming anything compiles. Typed routes are generated by the dev
  server, so start it once before the first typecheck in a fresh clone.

## Conventions

- Files: PascalCase components, camelCase everything else. Imports via `@/`.
- Colors only from `useTheme()` or `src/constants/theme.ts`. Never hardcode in screens.
- Data model changes: bump the persist `name` in `src/store/games.ts` (`chalk.games.vN`) or add
  a `migrate`. Users' games live only on their phones; do not strand them.
- Commits: conventional (`feat:`, `fix:`, `chore:`), one logical change each.
